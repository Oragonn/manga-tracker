# 📚 **Manga Tracker – Complete Project Summary (Updated January 2026)**

## 🎯 **Project Overview**

A self-hosted manga/manhwa tracking application that monitors 1,300+ series across multiple sources (MangaDex, Kagane) with manual chapter control, automated checking, bulk operations, activity logging, automated backups, multi-source support per series, and comprehensive statistics dashboard.

---

## 🏗️ **Architecture**

### **Tech Stack**
- **Backend**: Python 3.9+, Flask, SQLite (WAL mode)
- **Frontend**: Vanilla JavaScript, Custom CSS (no frameworks)
- **Special**: Selenium for Kagane (Cloudflare bypass)
- **Integrations**: MangaDex API, Kagane scraper, AniList enrichment

## 🗄️ **Database Schema**

### **Core Tables**

#### `series` - Main series tracking
```sql
CREATE TABLE series (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    title_en TEXT,
    title_romaji TEXT,
    title_native TEXT,
    source_url TEXT NOT NULL UNIQUE,              -- Legacy: kept for backward compatibility
    cover_url TEXT,
    banner_url TEXT,
    status TEXT NOT NULL CHECK(status IN ('reading', 'plan_to_read', 'on_hold', 'dropped', 'completed')),
    source_status TEXT,                            -- Publication status
    source_type TEXT DEFAULT 'other',              -- manga/manhwa/manhua/other
    anilist_id INTEGER,
    alt_titles TEXT,                               -- JSON array
    current_chapter REAL NOT NULL DEFAULT -1,
    current_volume TEXT,
    latest_chapter REAL,
    total_chapters INTEGER DEFAULT 0,
    latest_release DATETIME,
    last_check DATETIME,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    genres TEXT,                                   -- JSON array
    content_rating TEXT DEFAULT 'unknown',         -- safe/mild/mature/explicit
    searchable_text TEXT                           -- Normalized search index
);
```

#### `series_sources` - Multi-source support
```sql
CREATE TABLE series_sources (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    series_id INTEGER NOT NULL,
    source_url TEXT NOT NULL UNIQUE,
    source_type TEXT NOT NULL,                     -- 'mangadex', 'kagane', etc
    is_primary BOOLEAN DEFAULT 0,                  -- Which source is "main"
    last_check DATETIME,
    added_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (series_id) REFERENCES series(id) ON DELETE CASCADE
);
CREATE INDEX idx_sources_series ON series_sources(series_id);
CREATE INDEX idx_sources_primary ON series_sources(series_id, is_primary);
CREATE UNIQUE INDEX idx_sources_url ON series_sources(source_url);
```

#### `chapters` - Chapter history per series
```sql
CREATE TABLE chapters (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    series_id INTEGER NOT NULL,
    volume TEXT,
    raw_chapter TEXT,
    chapter_number REAL NOT NULL,
    title TEXT,
    release_date DATETIME,
    chapter_url TEXT,
    is_oneshot BOOLEAN DEFAULT 0,
    FOREIGN KEY (series_id) REFERENCES series(id) ON DELETE CASCADE
);
```

#### `activity_log` - User action history with undo
```sql
CREATE TABLE activity_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
    action_type TEXT NOT NULL,                     -- 'added', 'deleted', 'progress', 'status', 'edited'
    series_id INTEGER,                              -- NULL if deleted
    series_title TEXT,
    old_value TEXT,                                 -- JSON: before state
    new_value TEXT,                                 -- JSON: after state
    is_bulk BOOLEAN DEFAULT 0,
    bulk_id TEXT,                                   -- Groups bulk operations
    can_undo BOOLEAN DEFAULT 1,
    FOREIGN KEY (series_id) REFERENCES series(id) ON DELETE SET NULL
);
CREATE INDEX idx_activity_timestamp ON activity_log(timestamp);
CREATE INDEX idx_activity_type ON activity_log(action_type);
CREATE INDEX idx_activity_bulk ON activity_log(bulk_id);
```

#### `meta` - Application metadata
```sql
CREATE TABLE meta (
    key TEXT PRIMARY KEY,
    value TEXT
);
-- Keys: 'last_dashboard_visit', 'schema_version'
```

## 🔧 **Multi-Source Architecture**

### **Overview**
A single series can track chapters from multiple sources simultaneously (e.g., MangaDex + Kagane). This is **user-controlled** - the system never auto-links sources.

### **Why User-Controlled?**
- Series with same name ≠ always same series
- Example: "Solo Leveling" could be:
  - Solo Leveling (manhwa)
  - Solo Leveling (light novel)
  - Solo Leveling (different translations)
- User must confirm which sources belong together

### **Database Design**
Uses a separate `series_sources` table:
```sql
series (1) → (N) series_sources
- Each series can have unlimited sources
- One source is marked as "primary"
- Legacy source_url column kept for backward compatibility
```

### **User Workflows**

#### **Adding a Second Source**
1. Open series settings (gear icon)
2. Click "Add Another Source" button
3. Paste URL (MangaDex or Kagane)
4. System validates URL type
5. Click "Add" → fetches chapters
6. Chapters merged with existing sources
7. Alt titles and genres merged automatically

#### **Reordering Sources (Primary Selection)**
1. Open series settings → Sources section
2. Drag-and-drop sources to reorder
3. Top source = primary source
4. Used for "Go to Source" button on card
5. Changes saved on modal close

#### **Removing a Source**
1. Open series settings → Sources section
2. Click trash icon next to non-primary source
3. Confirm deletion
4. Source removed, chapters remain
5. Cannot remove last source or primary (must reorder first)

### **Chapter Merging Logic**
When a series has multiple sources:

```python
def merge_chapters_from_sources(series_id):
    """Merge chapters from all sources."""
    sources = get_sources_for_series(series_id)
    all_chapters = []
    
    for source in sources:
        chapters = fetch_chapters(source.url)
        for ch in chapters:
            ch['source_id'] = source.id
            ch['source_type'] = source.source_type
        all_chapters.extend(chapters)
    
    # Deduplicate by chapter number (keep most recent)
    unique_chapters = {}
    for ch in all_chapters:
        ch_num = ch['chapter_number']
        if ch_num not in unique_chapters or ch['release_date'] > unique_chapters[ch_num]['release_date']:
            unique_chapters[ch_num] = ch
    
    return sorted(unique_chapters.values(), key=lambda x: x['chapter_number'])
```

**Example:**
- MangaDex: Ch. 1-150 (primary)
- Kagane: Ch. 145-149 (secondary, released earlier)
- Result: Ch. 1-150 (uses Kagane for 145-149 if newer release date)

### **Metadata Merging**
When adding sources:
- **Alt titles**: Combined from all sources (deduplicated)
- **Genres**: Combined from all sources (deduplicated)
- **Searchable text**: Rebuilt with all titles
- **Cover/banner**: Uses primary source (user can manually override)

### **Activity Logging**
Source changes are logged:
```json
{
  "action_type": "edited",
  "series_id": 123,
  "old_value": {
    "sources": [{"url": "...", "type": "MangaDex", "is_primary": true}]
  },
  "new_value": {
    "sources": [
      {"url": "...", "type": "MangaDex", "is_primary": true},
      {"url": "...", "type": "Kagane", "is_primary": false}
    ]
  }
}
```

## 🌟 **Special Features**

### **Season-Aware Parsing (Kagane)**
Handles series where seasons reset chapter numbering:

**Problem:**
- Season 1: Episode 1-65
- Season 2: (S2) Episode 1-23

**Solution:**
- Detects season markers: `(S2)`, `[Season 2]`, `{S3}`, etc.
- Calculates offset: Season 2 offset = 65 (last of Season 1)
- Applies offset: `(S2) Episode 1` → Chapter 66
- Result: Continuous numbering (1-88), no data loss

**Supported Formats:**
- Prefixes: `(S2) Episode 3`, `[Season 2] Episode 3`, `S3 Episode 3`
- Suffixes: `Episode 65 (Season 1 Finale)`, `Episode 1 (S2 Premiere)`
- Combined: `(S2) Episode 1 (Season 2 Premiere)`

### **Smart Search**
- Searches across: main title, English title, romaji, native, alt titles
- Normalized matching: removes punctuation, diacritics
- Multi-word support: all words must match (AND logic)

### **Volume-Aware Sorting**
For manga with volumes:
- Chapters sorted by volume first, then chapter number
- Dropdown shows: "Vol.3 Ch.25" instead of just "Ch.25"
- Handles numeric volumes (1, 2, 3) and text volumes

### **Adaptive Checking**
Background scheduler checks series at different intervals:
```python
intervals = {
    'reading': 1800,        # 30 minutes - actively reading
    'plan_to_read': 10800,  # 3 hours - might start soon
    'on_hold': 86400,       # 24 hours - paused
    'dropped': 604800,      # 7 days - rarely check
    'completed': 604800     # 7 days - might get extras
}
```
